# 15 — Voices: Catalog, Settings, Cloning

Router: `apps/api/src/va_api/routers/voices.py`. Envelope: **legacy**. Vendor: ElevenLabs only
(`provider='elevenlabs'`). Vendor REST calls go through `va_elevenlabs.rest.ElevenLabsRest`
(`09-tts-elevenlabs.md` owns the streaming client; this spec owns catalog and cloning).

## 1. Visibility model

A caller in org O sees:
1. **Platform catalog** voices: `voices.org_id IS NULL AND is_public = true` (curated premade ElevenLabs voices).
2. **Org voices**: `voices.org_id = O` (clones, imported shared voices).
Voice lookup by name (Send Call `voice: "Karen"`) is case-insensitive: org voices first, then platform. By UUID: our
`voices.id`. By ElevenLabs id (`voice: "eleven:<voice_id>"`): org row with that `provider_voice_id`, else platform row,
else (org setting `voices.allow_raw_provider_ids=true`) an ephemeral voice using that id with default settings.
Default voice when none given: platform voice named by `PLATFORM_DEFAULT_VOICE` setting = `"Karen"` (must exist in
the curated catalog seed, §2.3).

## 2. Platform catalog sync (`VoiceCatalogSyncWorkflow`, Temporal schedule daily 03:00 UTC + manual trigger
`POST /internal/admin/voices/sync`)

1. Page through ElevenLabs `GET /v2/voices?page_size=100&include_total_count=false&category=premade` with
   `next_page_token` until `has_more=false`.
2. For each voice in the curated list (§2.3) upsert a platform row: `provider_voice_id=voice_id`, `name` (curated
   display name), `description`, `category='premade'`, `tags` from labels values plus `"curated"`, `gender`, `accent`,
   `age` from `labels`, `language_codes` from `verified_languages[].language` (fallback `{en}`), `preview_url`,
   `settings` defaults (or vendor `settings` when present), `service='ELEVEN_FLASH'`, `is_public=true`.
3. Curated voices missing upstream → `is_public=false` (kept for existing references) and alert log.
4. Non-curated premade voices are not exposed.

### 2.3 Curated list
Stored in `packages/va_elevenlabs/src/va_elevenlabs/catalog.yaml`, entries
`{display_name, provider_voice_id, tags, recommended_for:[...]}`. The initial file is generated by
`scripts/build_voice_catalog.py`, which calls `GET /v2/voices?category=premade` with the real key, lists every
premade voice, and writes all of them with `display_name` = ElevenLabs name; it then adds the alias entry
`display_name: "Karen"` mapped to the first premade voice whose labels are `gender=female, accent=american` and
use case conversational (deterministic: sorted by name). The script is run once by a human with a live key
(documented in README); the committed YAML is the source of truth, and the simulator ships a fixture catalog with the
same structure so tests never need the live key.

## 3. Endpoints

| Method | Path | Purpose |
|---|---|---|
| GET | `/v1/voices` | List visible voices |
| GET | `/v1/voices/{voice_id}` | Voice detail (`voice_id` = uuid or name) |
| POST | `/v1/voices/clone` | Instant voice clone (multipart) |
| POST | `/v1/voices/{voice_id}/rename` | Rename org voice |
| PATCH | `/v1/voices/{voice_id}/settings` | Update default settings (org voices; platform voices → per-org override, §5) |
| GET | `/v1/voices/{voice_id}/settings` | Effective settings for this org |
| DELETE | `/v1/voices/{voice_id}` | Delete org voice (also deletes at ElevenLabs for clones) |
| POST | `/v1/voices/{voice_id}/rate` | Rate 1–5 |
| GET | `/v1/voices/{voice_id}/samples` | List samples |
| POST | `/v1/voices/{voice_id}/samples` | Add samples (multipart) → re-clone (ElevenLabs edit) |
| DELETE | `/v1/voices/{voice_id}/samples/{sample_id}` | Remove sample (re-clone) |
| POST | `/v1/voices/{voice_id}/sample` | Generate preview audio (TTS) |
| POST | `/v1/voices/import` | Import an ElevenLabs voice id from the org's own ElevenLabs library is **not supported**; this endpoint imports a *shared library* voice by `provider_voice_id` into the org (`category='shared'`) |

### 3.1 GET `/v1/voices`
Query: `scope?` (`all`|`platform`|`org`, default all), `search?`, `language?`, `gender?`, `tag?`, `limit≤200`,
`cursor?`. Response:
```json
{"status":"success","voices":[{"id":"…","name":"Karen","description":"…","provider":"elevenlabs",
 "provider_voice_id":"…","service":"ELEVEN_FLASH","category":"premade","public":true,"tags":["curated","female","american"],
 "language_codes":["en"],"gender":"female","accent":"american","age":"young","preview_url":"https://…",
 "average_rating":4.6,"total_ratings":120,"settings":{"stability":0.5,"similarity_boost":0.75,"style":0,
 "use_speaker_boost":true,"speed":1.0},"clone_status":null,"created_at":"…"}],"next_cursor":null}
```

### 3.2 POST `/v1/voices/clone` (multipart)
Fields: `name` (1–64, unique in org), `description?` (≤ 500), `files` (1–25 audio files), `remove_background_noise?`
(bool, default false), `labels?` (JSON object string, keys among `language`, `accent`, `gender`, `age`, `use_case`,
values ≤ 32 chars), `language_codes?` (JSON array).

Steps (synchronous part in API):
1. Permission: owner/admin/developer; plan cap: count org voices with `category='cloned' AND deleted_at IS NULL`
   ≥ `plans.voice_clone_cap` → 403 `VOICE_CLONE_LIMIT`.
2. Validate each sample (§4); failure → 400 `SAMPLE_INVALID` with `details.files:[{name, reason}]`.
3. Upload to S3 `s3://{S3_BUCKET_VOICES}/{org_id}/{voice_id}/{sample_id}.{ext}`; insert `voices` row
   (`category='cloned'`, `clone_status='processing'`, `provider_voice_id` = `"pending:" + voice_id`) and
   `voice_samples` rows.
4. Start `VoiceCloneWorkflow(voice_id)`; respond 202-like body with HTTP 200:
   `{"status":"success","voice_id":"…","clone_status":"processing"}`.

`VoiceCloneWorkflow` activity `create_ivc`:
1. Download samples from S3; `POST {ELEVENLABS_API_BASE}/v1/voices/add` multipart: `name` = `"{org_slug}:{name}"`
   (org-prefixed for operator traceability), `files` (each sample), `remove_background_noise`, `description`,
   `labels` (JSON string).
2. Response `{voice_id, requires_verification}` → set `provider_voice_id`, `clone_status='ready'` (if
   `requires_verification=true` → still ready but `tags` gets `"requires_verification"` and event data notes it).
3. Generate a preview: TTS of `"Hi, this is {name}. Thanks for calling — how can I help you today?"` →
   mp3 in S3 → `preview_url` (signed on read).
4. Emit `voice.clone_ready`; usage event `voice_clone` (quantity 1, price per plan feature table in 24).
5. Errors: ElevenLabs 422/400 → `clone_status='failed'`, `clone_error` = vendor `detail` message (first `msg`),
   emit `voice.clone_failed`. 401/403 → non-retryable platform alert. 429/5xx → retry 5 times (2 s, 4 s, 8 s, 16 s, 32 s).

### 3.3 Samples add/remove
Adding/removing samples calls ElevenLabs `POST /v1/voices/{provider_voice_id}/edit` (multipart `name`, `files`
— full current sample set re-uploaded, `remove_background_noise`, `description`, `labels`) via workflow activity
`edit_ivc`; `clone_status` cycles `processing → ready|failed`.

### 3.4 DELETE
Org voices only (platform → 403 `FORBIDDEN`). Soft delete row; for `cloned` call ElevenLabs
`DELETE /v1/voices/{provider_voice_id}` (404 tolerated); S3 samples deleted by retention job after 30 days.
Calls/agents referencing the voice fall back to the platform default with `call.error` warning `VOICE_NOT_FOUND`.

### 3.5 Rate
`{"rating": 1..5}` → upsert `voice_ratings`; maintain `rating_sum/count` in the same transaction.

### 3.6 Preview `POST /v1/voices/{id}/sample`
Body `{"text": "≤ 300 chars", "settings?": VoiceSettings, "output_format?": "mp3_44100_128"|"ulaw_8000"}` → returns
`audio/mpeg` (or `audio/basic`) bytes using ElevenLabs REST `POST /v1/text-to-speech/{voice_id}` with
`model_id=ELEVENLABS_TTS_MODEL`. Rate limit 10/min per org. Metered as `tts_characters`.

## 4. Sample validation
- Accepted MIME/ext: `audio/mpeg` (.mp3), `audio/wav`/`audio/x-wav` (.wav), `audio/x-m4a`/`audio/mp4` (.m4a),
  `audio/ogg` (.ogg), `audio/flac` (.flac), `audio/webm` (.webm).
- Duration measured with **`mutagen`** (`mutagen.File(path).info.length`; WAV via `mutagen.wave`). Unreadable →
  invalid "unreadable audio".
- Per file: 1 s ≤ duration ≤ 600 s, size ≤ 25 MB. Total duration across files: ≥ 5 s and ≤ 600 s (recommended
  60–180 s; response includes `warnings` when total < 30 s: "Clones improve with at least 30 seconds of clean
  speech").
- Magic-byte check matches extension (reject mismatches).

## 5. Voice settings

```python
class VoiceSettings(BaseModel):
    stability: float = Field(0.5, ge=0, le=1)
    similarity_boost: float = Field(0.75, ge=0, le=1)
    style: float = Field(0.0, ge=0, le=1)
    use_speaker_boost: bool = True
    speed: float = Field(1.0, ge=0.7, le=1.2)
```
Effective settings precedence (per call): call `voice_settings` param → pathway node/global override
(`global_config.voiceSettings`) → persona/agent config → org override for that voice (org setting
`voice_overrides[voice_id]`, written by PATCH settings on platform voices) → voice row `settings` → model defaults.
Sent to ElevenLabs in the multi-stream `voice_settings` of context initialization (09).

## 6. Data and S3
- Tables `voices`, `voice_samples`, `voice_ratings` (03 §5).
- Preview and sample objects use SSE (KMS in AWS). Signed GET URLs 1 h.

## 7. ElevenLabs error mapping
| Vendor response | Our code | HTTP |
|---|---|---|
| 401/403 | `INTERNAL_ERROR` (platform credential issue, alert) | 500 |
| 422 `detail[]` | `VOICE_CLONE_FAILED` (`details.provider_message`) | 502 (async → clone_error) |
| 400 with `voice_limit_reached` / quota detail | `VOICE_CLONE_FAILED` + platform alert | 502 |
| 404 on voice | `VOICE_NOT_FOUND` | 404 |
| 429 | retried; final → `UPSTREAM_TIMEOUT` | 504 |
| 5xx / timeout | retried; final → `UPSTREAM_TIMEOUT` | 504 |

## 8. Permissions
List/get/preview: all roles except billing. Clone/rename/settings/samples/delete/import: owner, admin, developer.
Rate: any member. API key scopes `voices:read`, `voices:write`.

## 9. Tests required
- Visibility and name resolution order; raw provider id setting.
- Catalog sync with simulator: upsert, curated filtering, upstream removal, pagination tokens.
- Clone: cap enforcement, validation matrix (format mismatch, durations, sizes, totals), S3 writes, workflow success,
  422 failure, retry on 5xx, requires_verification tagging.
- Sample add/remove triggers edit; delete calls vendor delete; fallback warning in calls.
- Settings precedence matrix; range validation.
- Rating aggregation concurrency (two parallel ratings).
- Preview rate limit and metering.

## 10. Acceptance criteria
- Cloned voice becomes usable in a simulator call within one workflow run, and the call's TTS context uses its
  `provider_voice_id` and effective settings.
- `GET /v1/voices` p95 < 80 ms with 5 000 voices.
